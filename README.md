# RecipeGram

Безкоштовний статичний вебзастосунок для приблизного перерахунку кулінарних об'ємів у масу.

## Запуск
Відкрийте папку у VS Code. Для локального запуску використайте розширення Live Server (щоб завантажувався `ingredients.json`) або відкрийте `index.html` напряму — базові густини вже вбудовані в JavaScript.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Обмеження
Підтримуються рядки формату `500 мл молока`, `2 склянки борошна`, `3 шт яйця`. URL-рецепти не імпортуються. Перерахунок об'єму у масу є приблизним, похибка не гарантована. Ложки та склянки трактуються як 15, 5 і 250 мл відповідно. Для точних рецептів використовуйте кухонні ваги.

## Зміна кількості порцій
Вкажіть, на скільки порцій розрахований початковий рецепт, та скільки порцій потрібно. Кнопки + і − змінюють кількість порцій; усі розпізнані кількості інгредієнтів множаться на відношення нових порцій до початкових. Наприклад, 2 → 6 порцій = ×3. Кількісні одиниці (шт., зубчики) залишаються кількісними; можливі дробові значення.


## Список покупок

Відкрий вкладку «Рецепти», введи інгредієнти та вибери кількість порцій. Натисни «Додати інгредієнти до покупок», щоб перенести розраховані кількості у вкладку «Покупки». Там можна вручну додавати позиції, відмічати куплене та видаляти його. Список зберігається в localStorage конкретного браузера, не синхронізується між пристроями. Повторне натискання кнопки додає позиції повторно.
